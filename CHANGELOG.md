# Журнал изменений

## 0.4.0-rc.5 — 2026-11-01

Сборка `20261101.3`. Кандидат. Стабильная 0.4.0 не объявляется. Физические USB не подключались.

- Новое поле `source_dependency`: `required`, `not_required` или `unknown`. Короткий `status` говорит, нужен ли ещё исходный носитель: «Источник: ещё требуется для копирования.», «Источник: пока требуется.» до `READY` локальной копии, «Источник: больше не требуется Quiet USB Copy.» после неё, «Источник: статус неизвестен.» при неподтверждённой или повреждённой копии. Значение пересчитывается при сохранении и при `status`, подмена строки в файле состояния ответ не меняет.
- Экран перед запуском без английских меток: «Режим: прямой», «Размещение: корень назначения» или «отдельная папка». Объём и свободное место — отдельные строки «Копирование:» и «Свободно:».
- Меньше внешних процессов на файл: печатные ASCII-имена кодируются одним `awk`, сложение и сравнение чисел до 2^32 идут в оболочке, точки монтирования источника и назначения ищутся за один проход, тип и отпечаток файла берутся одним `stat`, родительский каталог вычисляется без внешней команды.
- Справка упоминает `source_dependency` и пункт `[4]`. Четыре новые проверки поля и фраз об источнике.
- В наборе поднят предел ожидания `wait_done`: не меньше 60 секунд, переменная `QUC_TEST_WAIT_MIN`. Под нагрузкой задание может несколько секунд оставаться в `CREATED`. Завершённое задание по-прежнему возвращается сразу. Двадцать полных прогонов подряд прошли, в каждом 106 из 106.

## 0.4.0-rc.4 — 2026-11-01

Сборка `20261101.2`. Кандидат. Стабильная 0.4.0 не объявляется. Физические USB не подключались.

- Ожидание фазы в наборе больше не зависит от короткого потолка в 16 секунд. Условие успеха — появление фазы. 80 секунд остаются только пределом зависания. Двадцать полных прогонов подряд прошли, в каждом 102 из 102.
- `doctor` без назначения печатает диагноз возможностей: `SUPPORTED`, `LIMITED` или `UNSUPPORTED`. Неустановленная черта остаётся `UNKNOWN` и не становится `SUPPORTED`. На этой машине итог `LIMITED`, потому что `fs_gate=UNKNOWN`. Проба записи одна на процесс и лежит в частном каталоге, не на флешке. Если безопасная запись или публикация нового имени недоступны, копирование отказывается.
- Экран перед запуском показывает источник, назначение, направление, объём, режим, размещение и один вердикт. Ограничение не подписывается словом OK. Подробности открывает `[2]` и задание не создаёт. Смена выбора — `[3]`. Локальная копия — `[4]`, только когда она доступна. Обычный запуск по-прежнему три ответа, после старта вопросов нет.
- Короткий `status` отдельно называет копирование, проверку содержимого и синхронизацию. Добавлены строки готовности или повреждения локальной копии и возможности восстановления, только когда запись задания это подтверждает. Подробности — `report --verbose`. Машинные поля прежние. Успешный `sync` не разрешает извлекать накопитель.
- Новые проверки: подмена промежуточного каталога ссылкой, повреждённая локальная копия перед продолжением, отсутствие служебных имён после успеха, подробности без запуска.
- Парный замер на tmpfs против rc.2 и rc.3 не показал роста медианы короткого DIRECT больше чем на 10% относительно rc.3. Проверки inode и публикация не снимались. Числа tmpfs не являются скоростью USB.
- Добавлена команда разработчика `sh tests/check.sh`. Для копирования она не нужна.

## 0.4.0-rc.3 — 2026-11-01

Сборка `20261101.1`. 98 автоматических проверок.

- Публикация без принудительной замены данных. Новое имя ставится жёсткой ссылкой с проверкой inode, затем `mv -n`. Запасного `mv -f` для данных больше нет. Если безопасный перенос не получился, чужой объект не меняется и итог не `SUCCESS`.
- `resume` не заменяет уже опубликованный файл, который изменился. Пропуск только после `cmp` или совпадения сумм источника и назначения с записью.
- Временный файл открывается с запретом перезаписи, запись идёт в унаследованный дескриптор. Символьная ссылка на месте временного имени больше не снимается: вызов отказывает.

## 0.4.0-rc.2 — 2026-10-31

Сборка `20261031.2`. 80 автоматических проверок.

- Поиск точки монтирования — один проход `awk` по `/proc/self/mountinfo` вместо процесса на каждую строку. Прямое копирование не медленнее 0.3.0.
- Публикация не считает код 0 у BusyBox `mv -n` при занятом имени успехом.
- Номер inode каталога записи проверяется вместе с меткой носителя и в файл состояния не пишется.
